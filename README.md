# CozyHaven Stay
### Full-Stack Hotel Booking System

A full-stack hotel booking application built using **React, ASP.NET Core Web API, and Microsoft SQL Server**, demonstrating modern web development, API integration, database management, and authentication.

## Tech Stack

- **Frontend:** React, JavaScript, Tailwind CSS
- **Backend:** C#, ASP.NET Core Web API
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework Core
- **Authentication:** JWT
- **Password Hashing:** BCrypt

## Features

- Full-stack web application architecture
- React-based user interface
- RESTful API integration
- SQL Server database integration using Entity Framework Core
- JWT-based authentication infrastructure
- BCrypt password hashing
- Separation of frontend and backend components
